# עומק — מערכת תנועה ומפת תנועה (גרסה 2: עיצוב יוקרה)

סטטוס: נבנה, 7 באוקטובר 2026. מחליף את גרסה 1 (מודול א'-3).

**למה השתנה:** בגרסה 1 האתר היה שקט בכוונה, ונפסלו בה מסך פתיחה, סמן מותאם ו-Lenis. אבישי החליט שהאתר של הסטודיו הוא קודם כל הוכחת יכולת ללקוחות, ובחר במפורש: GSAP ו-Lenis, סמן מותאם, חשיפת טקסט, מסך פתיחה, עבודות בגלילה נעוצה, מעברי עמוד, גרעין, צליל, "ועוד כל מה שאפשר". המסמך הזה משקף את ההחלטה.

**מה לא השתנה:** הפחתת תנועה מכובדת בכל מקום, יש כפתור השהיה, הצליל כבוי כברירת מחדל, ושום אנימציה לא חוסמת לחיצה או הקלדה.

## ספריות

| ספרייה | שימוש |
|---|---|
| CSS | מסך הפתיחה, מסך מעבר העמוד, חשיפת כותרות מילה-מילה, חשיפה בגלילה, Marquee, גרעין, כפתורים. עובד גם בלי JS |
| Lenis (על ה-ticker של GSAP) | גלילה חלקה. כבויה בהפחתת תנועה, בתוך דיאלוגים ובמגירה |
| GSAP + ScrollTrigger | עבודות בגלילה אופקית נעוצה, ו"השיטה" בשכבות נעוצות. רק במסך 1024px ומעלה, ולא בהפחתת תנועה |
| three.js | צדפת הפנינה ב-Hero, הבושם והיהלום (ראו `3d-concept.md`) |
| Web Audio | צליל אווירה רגוע (פד לאונג' עם פעמונים רכים) ופעמון שקט במעבר על קישורים. רק אחרי לחיצה של הגולש |

כל הספריות נטענות ב-dynamic import אחרי שהעמוד מוצג.

## טוקנים

`--ease-lux` (`cubic-bezier(0.22, 1, 0.36, 1)`) לתנועות גדולות, `--ease-out` לכניסות קצרות. `--intro-ms` הוא 1300ms. הטוקנים הקודמים (`--motion-*`) נשארו למיקרו-אינטראקציות.

## הגבלות שנשמרו

- **מובייל:** חוויה מאוזנת. הסצנה באיכות מופחתת, בלי גלילה נעוצה ובלי סמן.
- **ביצועים:** אם החציון של זמן הפריים גבוה מ-45ms, הסצנה עוברת לפוסטר עד סוף הביקור.
- **נגישות:** הקנבס `aria-hidden`. כפתורי ההשהיה והצליל הם כפתורים אמיתיים עם תווית ו-`aria-pressed`. בדיאלוג הפתוח הסמן הרגיל חוזר.
