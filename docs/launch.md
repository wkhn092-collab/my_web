## 2. דומיין

**`omek.co.il` כנראה תפוס** (יש לו רישום, ה-DNS שלו פשוט לא עובד). השמות האלה לא רשומים לפי בדיקת DNS מ-8.10.2026. הבדיקה הסופית היא אצל רשם הדומיינים:

| הצעה | למה |
|---|---|
| **omekstudio.co.il** (מומלץ) | ברור, קל להכתיב בטלפון, אין מקפים |
| omek-studio.co.il | אותו דבר עם מקף. כדאי לקנות גם אותו ולהפנות לראשון |
| beomek.co.il | "בעומק". קצר ומיוחד, אבל צריך להסביר איך כותבים |
| omekweb.co.il | אומר מיד שזה אתרים |
| omeksites.co.il | כמו למעלה |

**איפה קונים:** כל רשם מורשה של איגוד האינטרנט הישראלי (רשימה ב-isoc.org.il). מחיר טיפוסי: עשרות שקלים לשנה. חשוב: **הדומיין רשום על שמך**, לא על שם הרשם.

**אחרי הקנייה (DNS):**
1. Vercel ← Project ← Settings ← Domains ← Add ← `omekstudio.co.il`, ואחר כך גם `www.omekstudio.co.il`.
2. Vercel מראה בדיוק אילו רשומות להוסיף אצל הרשם. בדרך כלל:
   - לדומיין עצמו: רשומת `A` לכתובת ש-Vercel מציג.
   - ל-`www`: רשומת `CNAME` לכתובת ש-Vercel מציג.
3. מגדירים את הדומיין בלי `www` כראשי, ואת `www` כהפניה אליו.
4. **מיילים (חשוב גם אם אין לך מייל על הדומיין):** כדי שאף אחד לא יוכל לשלוח מיילים מזויפים בשם הדומיין, מוסיפים אצל הרשם:
   - `TXT` בשם `@` עם הערך `v=spf1 -all` (אם תשלח מיילים דרך Resend מהדומיין, Resend ייתן ערך אחר במקום זה).
   - `TXT` בשם `_dmarc` עם הערך `v=DMARC1; p=reject; rua=mailto:wkhn091@gmail.com`.
   - אם תחבר את הדומיין ל-Resend: הוא נותן רשומות `DKIM` ו-`SPF` משלו. מוסיפים בדיוק את מה שהוא מציג.

**מה מעדכנים אחרי שהדומיין עובד:**
- Vercel: `NEXT_PUBLIC_SITE_URL=https://omekstudio.co.il`, ואז Redeploy.
- Sanity ← API ← CORS origins: להוסיף את הדומיין החדש.
- Cloudflare Turnstile ← Hostnames: להוסיף את הדומיין החדש.
- Sanity ← Webhooks: לעדכן את הכתובת ל-`https://omekstudio.co.il/api/revalidate`.
- בקוד (אני אעשה את זה כשתגיד לי את השם): `public/.well-known/security.txt`, והקישורים בבוט (`omek-bot/src/business/knowledge.ts`, `bot.config.ts`, `tests/client.test.mts`).
- Meta: כתובת ה-webhook של הבוט, אם הבוט יושב על הדומיין הזה.

## 3. Google Search Console (שגוגל יכיר את האתר)

1. נכנסים ל-[search.google.com/search-console](https://search.google.com/search-console) עם חשבון ה-Google שלך.
2. Add property ← **Domain** ← מקלידים את הדומיין.
3. גוגל נותן רשומת `TXT`. מוסיפים אותה אצל הרשם ולוחצים Verify (לפעמים לוקח כמה דקות).
4. Sitemaps ← מקלידים `sitemap.xml` ← Submit.
5. אחרי יום-יומיים: בדוחות "Enhancements" רואים את השאלות הנפוצות ואת פירורי הלחם, אם גוגל קרא אותם.

**בדיקה מיידית:** [Rich Results Test](https://search.google.com/test/rich-results) על דף הבית ועל עמוד פרויקט. אמורים להופיע: Local business, FAQ, Breadcrumbs.

## 5. וואטסאפ: התראה עליך ובוט ללקוחות

יש כאן שני דברים נפרדים שמשתמשים באותו חשבון Meta:

| | מה זה | איפה הקוד |
|---|---|---|
| **התראה על פנייה** | כשמישהו ממלא את הטופס באתר, מגיעה אליך הודעת וואטסאפ | באתר (`omek-studio`) |
| **בוט ללקוחות** | מי שכותב למספר הוואטסאפ של העסק מקבל תשובה אוטומטית, ואם הוא רוצה שיחה או הצעת מחיר, אתה מקבל התראה | פרויקט נפרד (`omek-bot`) |

**למה הבוט בפרויקט נפרד:** הבוט ציבורי ומשתמש ב-AI. האתר מחזיק את המפתח שכותב למאגר הפניות. אם מישהו יצליח לתמרן את הבוט, הוא לא יגיע לפניות. זה עיקרון "הגנה בשכבות" מחוק האבטחה.

### 5.1 החלטה אחת לפני הכל: איזה מספר

ה-API הרשמי של וואטסאפ מחבר **מספר טלפון אחד לבוט**. המספר הזה לא יכול לקבל התראות מעצמו. לכן צריך **שני מספרים**:
- **מספר העסק** (עליו הבוט עונה, והוא המספר שבכפתור הוואטסאפ באתר).
- **המספר הפרטי שלך** (אליו מגיעות ההתראות).

היום הכפתור באתר מוביל ל-`050-396-7230`. זו השאלה הפתוחה הראשונה בסוף הדוח.

### 5.2 הקמה ב-Meta (פעם אחת)

ההוראות המלאות באנגלית ב-`omek-bot/README.md` (סעיף "Meta setup"). בקצרה:
1. [developers.facebook.com](https://developers.facebook.com) ← אפליקציה חדשה מסוג Business ← מוסיפים WhatsApp.
2. מוסיפים ומאמתים את מספר העסק. מעתיקים את **Phone number ID**.
3. Business Settings ← System users ← יוצרים משתמש ← **מפתח קבוע** עם `whatsapp_business_messaging` ו-`whatsapp_business_management`. (המפתח הזמני מהלוח מת אחרי 24 שעות.)
4. App settings ← Basic ← מעתיקים את **App secret**.
5. מעבירים את האפליקציה ל-**Live**.

### 5.3 התראה על פנייה (באתר)

1. ב-`omek-studio/.env.local` ממלאים: `WA_ACCESS_TOKEN`, `WA_BUSINESS_ACCOUNT_ID`.
2. מריצים: `npm run whatsapp:template`. זה שולח ל-Meta את נוסח ההודעה לאישור (בדרך כלל דקות):
   > 📩 פנייה חדשה מהאתר
   > שם: דנה כהן
   > סוג אתר: אתר תדמית
   > טלפון: 050-123-4567
   > הפרטים המלאים במייל ובסטודיו.
3. ב-Vercel של האתר מוסיפים: `WA_PHONE_NUMBER_ID`, `WA_ACCESS_TOKEN`, `OWNER_WHATSAPP` (המספר הפרטי שלך, ספרות בלבד: `9725...`), `LEAD_ALERT_TEMPLATE=omek_new_lead`. Redeploy.
4. שולחים טופס בדיקה מהאתר.

**מה נשלח ל-Meta:** רק שם, סוג אתר וטלפון. ההודעה החופשית והמייל של הפונה **לא** נשלחים בוואטסאפ, רק במייל. מדיניות הפרטיות עודכנה בהתאם (צריך להעתיק את הנוסח החדש גם לעמוד הפרטיות ב-Sanity, ראו `docs/copy-deck.md`).

**אם ההתראה נכשלת:** הפנייה עדיין נשמרת ב-Sanity ומגיעה במייל. ההתראה היא תוספת, לא תחליף.

### 5.4 הבוט (`omek-bot`)

**מה כבר מוכן:**
- מאגר הידע של הבוט מלא בתוכן המאושר של האתר: סוגי האתרים, התוספות, השאלות הנפוצות, תהליך העבודה, השעות שלך. **בלי מחירים**. כששואלים כמה עולה, הבוט מסביר שיש הצעה כתובה אחרי שיחה, ואם הלקוח רוצה הצעה הוא מעביר אליך.
- הבוט מדבר עליך בגוף שלישי, אומר בכנות שהוא עוזר אוטומטי, לא מבטיח תאריכים או תוצאות, ולא מציג את פרויקטי הקונספט כעבודות ללקוחות.
- כשלקוח רוצה אתר, הדמיה או שיחה, הבוט "מעביר אליך": אתה מקבל התראה עם כפתור "החזרה לבוט", והבוט שותק מול הלקוח הזה עד שתלחץ (או 24 שעות).
- כל הבדיקות של הבוט עוברות, ו-`npm audit` מראה 0 בעיות.

**מה צריך כדי להפעיל:**
1. **מפתח OpenAI:** [platform.openai.com](https://platform.openai.com) ← API keys. עלות: הרבה פחות מאגורה לתשובה.
2. **Upstash Redis נפרד לבוט** (חינם): כדי שלא יענה פעמיים ויזכור שיחות. מומלץ מסד נפרד מזה של האתר, כדי שהבוט לא יוכל לגעת בהגבלות של הטופס.
3. **פרויקט Vercel חדש** לתיקייה `omek-bot` (ריפו נפרד ב-GitHub). המשתנים: הכל מ-`omek-bot/.env.example`. בעיקר: `WA_PHONE_NUMBER_ID`, `WA_ACCESS_TOKEN`, `WA_VERIFY_TOKEN` (מחרוזת אקראית שאתה ממציא), `WA_APP_SECRET`, `OPENAI_API_KEY`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `OWNER_PHONE_NUMBER` (המספר הפרטי שלך).
4. **תבנית התראת ההעברה:** בתיקייה `omek-bot`, `npm run create-alert-template`, ואחר כך `OWNER_ALERT_TEMPLATE=bot_handoff_alert` ב-Vercel של הבוט.
5. **חיבור ה-webhook ב-Meta:** WhatsApp ← Configuration ← Callback URL: `https://<כתובת הבוט>/api/whatsapp/webhook`, Verify token: הערך של `WA_VERIFY_TOKEN`, ומנויים ל-`messages`. ואז הפקודה `subscribed_apps` מה-README.
6. **בדיקה:** לכתוב לבוט מהטלפון הפרטי "כמה עולה אתר?", ואחר כך "אני רוצה לדבר עם אבישי". בשני המקרים אמורה להגיע אליך התראה.
7. **ביום שהבוט עולה:** להוסיף למדיניות הפרטיות את הפסקה המוכנה מ-`docs/copy-deck.md` (OpenAI ו-Upstash).

**עלויות:** Meta גובה לפי הודעה מעבר להקצאה החינמית (בערך 1,000 בחודש למספר, לפי שותפי Meta). OpenAI: אגורות בודדות לשיחה. Vercel: הבוט הוא שימוש מסחרי, ולכן צריך תוכנית Pro (כמו האתר).

## 6. ניטור זמינות (UptimeRobot)

1. נרשמים ל-[uptimerobot.com](https://uptimerobot.com) (התוכנית החינמית מספיקה).
2. Add New Monitor:
   - Monitor Type: **HTTP(s)**.
   - Friendly Name: `עומק`.
   - URL: `https://<הדומיין>/api/health`.
   - Monitoring Interval: 5 דקות.
3. Alert Contacts: האימייל שלך. אפשר להוסיף גם את אפליקציית UptimeRobot בטלפון להתראות.
4. (רשות) Keyword monitoring: לבדוק שהתשובה מכילה `OK`.

אם האתר נופל, מקבלים מייל תוך כמה דקות. מה עושים אז: `docs/security.md`, סעיף "אם משהו קרה".
